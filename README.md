Estech AI Business Copilot is an open-source AI-powered business operating system. Its intuitive interface combines AI communication, document generation, knowledge management, task tracking, and lead intelligence on one collaborative workspace. Deploy on cloud, VPS, or self-hosted, so small businesses move from manual workflows to intelligent automation without rebuilding the stack.

## Quick start

> Before installing Estech AI Business Copilot, make sure your machine meets the following minimum system requirements:
>
> - CPU >= 2 Core
> - RAM >= 4 GiB
> - Node.js >= 18.x
> - npm >= 9.x

The easiest way to start the server is through the command line. Before running the following commands, make sure you have Node.js and npm installed on your machine:

```bash
git clone https://github.com/Estech-ai-solutions/estech-ai-copilot-business-.git
cd estech-ai-copilot-business-
npm install
cp .env.example .env
npm run dev
```


After running, you can access the application in your browser at [http://localhost:3000](http://localhost:3000) and start the setup process.

## Key features

**1\. Communication Studio**: Generate professional customer replies, sales responses, and outreach messages in seconds. Download and send instantly. Every response is powered by your business context.

**2\. Document Studio**: Create quotes, invoices, proposals, contracts, and reports. Every document is formatted for clients and ready to download as PDF or DOCX.

**3\. Business Brain**: Store your pricing, services, FAQs, and policies. The AI references this automatically for accurate, on-brand responses every time.

**4\. Task Manager**: Convert AI suggestions into actionable tasks with deadlines, priorities, and status tracking. Keep your team aligned and moving.

**5\. Lead Intelligence**: Discover new prospects, score them automatically, and manage outreach from one place. Prioritize high-value leads and close faster.

**6\. Control Center**: Monitor usage, manage knowledge, generate content, and track analytics from one dashboard. Everything you need in one place.

**7\. AI Copilot**: Chat with an AI that knows your business. Ask questions, get suggestions, and automate repetitive work with natural language.

**8\. Content Generator**: Create marketing copy, social media posts, email campaigns, and ad creatives. Scale your content without scaling your team.

## Advanced Setup

### Custom configurations

If you need to customize the configuration, edit `.env.example`. The essential startup defaults include Mistral API configuration, Supabase connection, and application settings. After making any changes, re-run `npm run dev` from the project directory.

### Deployment with Docker

If you'd like to deploy with Docker, you can use the following Dockerfile as a reference:

```dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:18-alpine AS runner
WORKDIR /app
ENV NODE_ENV production
COPY --from=builder /app/public ./public
COPY --from=builder /app/.next/standalone ./
COPY --from=builder /app/.next/static ./.next/static
EXPOSE 3000
CMD ["node", "server.js"]
```

## Deployment with PM2

For production deployments, you can use PM2 to manage the Next.js process:

```bash
npm install -g pm2
pm2 start npm --name "estech-ai" -- start
pm2 save
pm2 startup
```

```bash
# AI configruation gemini
GEMINI_API_KEY = your-key
# AI Configuration other
MISTRAL_API_KEY=your-key
MISTRAL_API_URL=https://api.mistral.ai/v1/chat/completions
GROQ_API_KEY = your-key


# Authentication
JWT_SECRET=your-secret

# Database
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-key
```
